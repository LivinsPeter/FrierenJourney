# Beyond the Long Road

A small browser game prototype with a 240 × 160 HTML5 Canvas and crisp pixel scaling.

## Run

Open `index.html` directly in Chrome or Microsoft Edge. The starter shell uses no build tools, packages, or external assets. If your browser does not run the page correctly from a file, start a local server from this folder:

```powershell
python -m http.server 8000
```

Then visit <http://localhost:8000> in Chrome or Edge.

Press Enter or Space on the title screen to start the placeholder loop.
